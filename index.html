How I build AI systems

The habits behind every project above, from the first prototype to the deployed service.

  • Measure before tuning

    Golden sets decide what changes: RAGAS on 30 questions for retrieval, 40 questions for text-to-SQL, and field-level accuracy for extraction.

  • Guard the edges

    Out-of-scope refusals, read-only SQL with SELECT-only validation and row limits, and human approval before flagged results go through.

  • Trace every query

    Langfuse traces show latency and cost per query, and semantic caching stops repeat questions from costing twice.

  • Ship in containers

    FastAPI services in Docker and Docker Compose on AWS EC2 and S3, with Git, GitHub Actions and Jenkins for CI/CD.
